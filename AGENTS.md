## GGG art use

GGG art is never a reference or template for building Project Vaal's own original assets — UI chrome, branding, and decorative elements must be original, full stop. The exception is depicting real in-game content, where authentic GGG artwork is required for the result to be correct and recognizable: the passive skill tree (GGG-sanctioned tree-export sprites, `public/data/tree/`) and the wiki's item/gem/skill icons (extracted via `@poe2-toolkit`, official patch-server data, `public/data/wiki/`). Both exceptions are scoped to depicting actual game content pulled from GGG's own official data; do not extend either to any other feature, and never use GGG art as inspiration for something original-looking instead of the real thing.
